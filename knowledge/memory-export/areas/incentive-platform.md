- [stated] Problem: agent incentives across portals run entirely manually (set, tracked, reconciled by hand) and are static, with no way to shape different agent cohorts or timeframes; agents lack visibility into what they're earning or why; manual nature makes it hard for related teams to experiment and iterate on what moves behavior
- [stated] Solution proposal: an incentive platform where structures can be configured, run, and tracked per agent/cohort/portal, with real-time visibility for agents into active incentives and earnings, and automatic reconciliation
