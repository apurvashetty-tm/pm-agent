# Use Case Style Guide (fallback)
*Used only when no past PRDs are found in Drive.*

- Lead with the actor: *"When a [user/ops agent/system] does X under condition Y..."*
- State the expected outcome explicitly: *"...the system must Z."*
- Group sub-cases under a primary case using indented numbering (1.1, 1.2...).
- Cover failure modes immediately after the happy path for each primary case.
- Keep each use case to 2–4 sentences. If it runs longer, break it into sub-cases.
- Do not use passive voice. The actor must be named in every case.
