## Authority

- Strategy and initiative definitions: project truth.
- Numeric claims and wording: evidence register.
- Unresolved items: open questions.
- Structure: blueprint only after formal freeze.
- Expression: creative brief.
- Workflow/file ownership: agent runbook.

## Rules

- Keep each initiative in one primary home.
- Use evidence IDs for every number in working drafts.
- Never invent target, date, owner, estimate, status, attribution, or baseline.
- Never use CONFLICTED claim.
- Preserve hypothesis labels.
- Whiteboard strategy extraction is complete; re-open only on user request or specific evidence conflict.
- References are archived and non-authoritative.
- Page 11 is initiative lifecycle; Page 12 is written last.
- Propose structural improvements explicitly; do not silently change canonical files.
- Follow exclusive file ownership in runbook.

## After work

- Write only assigned output path.
- Report truth conflicts to coordinator.
- Only truth steward updates canonical context.
- Only coordinator updates `session_handoff.md`.
