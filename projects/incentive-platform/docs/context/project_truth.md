# project_truth.md — Incentive Platform

**Status:** Pre-PRD proposal. Not locked — nothing here has been validated with
business or engineering yet.
**Last updated:** 2026-09-25 (captured from an earlier chat thread; first time this
has been written to git)

## 1. The problem, as stated

Agent incentives across Truemeds' portals are run entirely manually today:
- Set, tracked, and reconciled by hand.
- Static — no way to shape incentives differently for different agent cohorts or
  timeframes.
- Agents lack visibility into what they're earning or why.
- Because it's manual, related teams find it hard to experiment and iterate on what
  actually moves agent behavior.

## 2. The proposed direction

An incentive platform where:
- Incentive structures can be configured, run, and tracked per agent / cohort / portal.
- Agents get real-time visibility into active incentives and what they're earning.
- Reconciliation happens automatically instead of by hand.

## 3. What's genuinely open

Everything below build scope, target portals/cohorts, how it plugs into existing
payroll/finance reconciliation, and how it relates to the ACOM portal-unification work
(shared agent tooling across portals) — none of this has been discussed yet. This file
exists to preserve the problem/solution framing, not to lock scope.
