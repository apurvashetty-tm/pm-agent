### Exact test-data oracle

From Logic:284–293 and Data:2–15: `9000000001` → Not registered/sign-up; `9000000002` → Account inactive/Call Doctor Ops; `9000000003` → Too many attempts/countdown; `9000000004` → Couldn't send; `9000000005` → Number locked. `1234` → Correct/signs in; `0000` → Code expired; `9999` → Couldn't verify/server error. Other valid mobile → Code sent/OTP; other OTP → Wrong code, tries count down, fifth locks. These are synthetic inputs, not personal data. This suite tests panel display and tap-fill; entry-journeys owns full authentication outcomes.
