## How to open a state

Open the file in a browser, or use the same URLs as `docs/renders/2026-10-15-standards/capture.py`:

- Sign-in: `sign-in/sign-in.html?capture=<state>` (`default`, `keyboard-open`, `empty-tap`, `too-short`, `wrong-first-digit`, `pasted-cleaned`, `sending`, `not-registered`, `offline`, `couldnt-send`, `too-many-tries`, `inactive`)
- OTP: `otp/otp.html?capture=<state>` (17 states, e.g. `verifying`, `locked`)
- Offer: `faster-signin-offer/faster-signin-offer.html?capture=<fingerprint | face-id | enabling>`
- Unlock: `returning-unlock/returning-unlock.html?capture=<fingerprint | face | screen-lock | pending | cancelled | platform-retry | unavailable>`
- Home: `home/home.html?state=<state>` (e.g. `setup-wheel`, `active`, `add-wheel`, `end-confirmation`)
- Case page: `case/case.html?s=<state>&start=case&capture=1` (add `&w=360` for the 360 width). Examples: `a-top`, `b-on-call`, `d-duration-picker`, `e-prescription-confirmed`.

`capture=` (and `?capture=1`) hides the review controls and sets the page to the screen width.
