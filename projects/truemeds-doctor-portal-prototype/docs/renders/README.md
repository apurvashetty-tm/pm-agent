# Renders — Doctor Portal prototype

Every image rendered while designing this prototype is kept here, one folder per day, numbered in the
order it was made. Why each one exists is in `docs/context/decision_log.md` (D-numbers below).

**Rule for every session (human or AI):** any image shown in a review — concepts, before/after, proposals,
research files — is saved here as `YYYY-MM-DD/NN_short-description.png` and listed below, in the same turn.
Automated test screenshots are not kept (they are regenerated by the tests).
