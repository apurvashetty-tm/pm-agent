## What is being checked (decision D-108, Truemeds design system)
Vertical spacing is measured between VISIBLE edges, never layout boxes:
- text: the glyph ink box of each line from Range client rects, trimmed to cap height (top) and the font's descender line (bottom), not the line box;
- filled or bordered shapes (background colour different from the parent's, a visible border, or a box-shadow): their painted border box; their children are not measured separately;
- images / svg icons: their painted bounds.
Tap areas (e.g. a transparent `::after` 48 px hit area on an inline link) and reserved empty lines (an empty element that only holds height) add NO visible edge.
Allowed gaps: 8, 16, 32, each with a tolerance of +/-2 px, plus a page's own listed anatomy exceptions. Anything else fails.

## The module contract (implement tests against exactly this)
File: design-system/scripts/check-visible-gaps.mjs (ES module). Exports:
- `async function launchBrowser()` -> a Playwright Browser (Chromium; the module resolves Playwright itself).
- `async function measurePage(page, options)` -> report object. `page` is a Playwright Page already loaded.
  options: `{ root?: string = 'body', regions?: [{ name: string, selector: string, edgeTop?: boolean = false }], allowed?: number[] = [8,16,32], tolerance?: number = 2, anatomy?: [{ above: string, below: string, gap: number, note?: string }], atomic?: string[], ignore?: string[] }`.
  If `regions` is omitted there is one region named 'root' = the root element.
  `edgeTop: true` means the region element's own top edge counts as the first visible edge (gap from it to the first content row is checked).
  Units that overlap vertically are merged into one row; gaps are between consecutive rows (row below top minus row above bottom).
  Report: `{ pass: boolean, failures: number, regions: [{ name, rows: [{ top, bottom, units: [{ label, kind: 'text'|'paint'|'image', top, bottom, left, right }] }], gaps: [{ above: string, below: string, px: number, expected: number, pass: boolean, rule: 'scale'|'anatomy'|'edge' }] }] }`.
  `px` is rounded to 0.1. `expected` is the matching allowed value (or anatomy value) when passing, else the nearest allowed value. `above` / `below` are short labels (text or a selector-like name) of the two rows.
