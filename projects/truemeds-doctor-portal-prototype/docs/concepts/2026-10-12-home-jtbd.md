# Doctor Home: jobs to be done (final)

**Status:** scope agreed 2026-10-12; screens not yet designed. Approved renders move to `ui-screens/`.
**Tags:** **Agreed** · **Proposed** (recommended, awaiting Apurva's yes) · **Verify** (backend or ops to confirm) ·
**Later** (parked).

## Purpose
Home is where the doctor rests between cases. It answers one question:
**"Am I taking cases right now, and what do I do next?"**
Anything that doesn't serve that question lives in the profile menu, not on Home.

**Who:** a registered doctor on a phone (mobile web today; native app later), working in self-chosen windows,
doing one case at a time.

---

## Job 1 · Start and stop taking cases
**When** I'm free to work, **I want** to say until when, **so** I only take cases I can finish.

| | |
|---|---|
| What it means | "Taking cases" = the doctor **may request** a case. Nothing is pushed. **Agreed** |
| Naming | "Taking cases", never "Online", so the meaning doesn't change silently if offers arrive later. **Agreed** |
| Start | Home's own state, not a pop-up. Main action **Start taking cases** opens a bottom sheet of end-time chips: next whole hours with duration (e.g. "6:00 PM · 4h 20m"), the usual end time pre-selected, plus "Other time". **Proposed (to judge from the render)** |
| Stop | **Stop taking cases** always one tap away while taking cases. **Proposed** |
| Breaks | No separate Break state in v1; stop and start again covers it. **Proposed** |
| App closed | Closing the app or locking the phone doesn't stop the window. On return Home shows the time left. **Proposed** |
| Success | Doctors set a window in one sheet; few windows abandoned in the first minute. |

## Job 2 · Get the next case
**When** I'm ready, **I want** a case in one tap, **so** I'm not waiting on anyone.

| | |
|---|---|
| Action | **Next order** (pull model). **Agreed** |
| Last-second rule | A request made before the window ends is honoured even if the case arrives after. **Agreed** |
| Between cases | After closing a case, Next order is on the case page; Home shows only when no case is waiting or the window has ended. **Agreed (D-31)** |
| No case | Clear "No cases right now" state with Try again. **Agreed as fallback** |
| Better no-case | "Looking for a case": one tap, the app re-checks while the doctor stays on Home and opens the case with a sound when found; Stop any time. **Verify (discuss, then backend)** |
| Success | Time from tap to case; repeated taps on "no cases" (should fall if "Looking" ships). |

## Job 3 · Know my time left and change it
**While** I'm working, **I want** to see when my window ends and stretch it, **so** I don't stop mid-flow.

| | |
|---|---|
| Always visible | Window end time on Home, with **Extend**. **Agreed** |
| Extend steps | +30 min, +1 h, +2 h. **Proposed** |
| Ending soon | Quiet "Ends in 15 min" notice on Home only, never on the case page. **Proposed** |
| Ends during a case | Never interrupts the case. Back on Home, Next order is replaced by **Extend** or **Done for now**. **Agreed** |
| Ends while idle | Home switches to "Not taking cases": "Your window ended at 6:00 PM" + Start again. **Proposed** |

## Job 4 · See today's progress
**At a glance, I want** to know how much I've done today.

| | |
|---|---|
| What | A count only; no earnings. **Agreed** |
| What counts | A case whose **prescription is generated** (Confirm on the case page). Callbacks, unavailable and rejected cases don't count. **Agreed** |
| Label | "Prescriptions today", so the number matches what's counted. Resets at midnight. **Proposed** |

## Job 5 · Get help fast, from anywhere, and report app problems
**When** something goes wrong, **I want** ops (and tech) to know what happened without me explaining it.

| | |
|---|---|
| Where | A help icon in the shared header, just left of profile, on Home **and inside a case**. **Agreed** |
| Help sheet | **Message support** (WhatsApp) and **Call Doctor Ops**. During a live patient call, Call is hidden; Message stays. **Agreed** |
| Channel v1 | WhatsApp hand-off; in-app chat later. **Agreed** |
| Message | Pre-filled with a reference ID, the order ID (if in a case), app version and phone. Never patient details, OTPs or notes. **Proposed** |
| Crash / freeze (ANR) data | Logged automatically to tech's crash-reporting tool. Tapping Help sends a report and gets the reference ID; ops passes it to tech. Report: app version, phone and OS/browser, network, current screen, order ID, recent errors and failed requests with times. **Proposed** |
| After a crash | Next launch offers "Something went wrong last time. Report it", report attached. **Proposed** |

## Job 6 · Read announcements and incentives
**I want** to see what ops is telling us, without hunting through WhatsApp.

| | |
|---|---|
| Where | A notifications bell on **Home only**, opening an inbox with an unread dot. Never inside a case. **Agreed** |
| Content | Ops announcements and incentives. **Agreed** |
| Push alerts when app is closed | **Later** |

## Job 7 · Trust the app is ready
**Before** I tap, **I want** to know it will work.

| | |
|---|---|
| Offline | Fixed-height strip at the top (never changes header height); Next order disabled with a reason. **Proposed** |
| Session expired | OTP sheet over Home, or over the case so no notes are lost; never a jump back to sign-in. **Proposed** |
| Background during a case | The case continues and resumes on return. **Agreed** |

## Job 8 · One phone at a time
| | |
|---|---|
| Rule | Sign in on any phone; only one active at a time. **Agreed** |
| New phone | "You're signed in on another phone. Continue here?" signs the other out. The old phone shows "Signed out because you signed in on another phone." **Proposed** |
| Live case on the old phone | Sign-in waits: "Finish your case on the other phone first." **Proposed** |

## Job 9 · Manage my account (profile menu)
Name and registration (read-only), faster sign-in on/off, help, **Log out** (hidden during a case). **Proposed**

## Home states to design (one at a time)
| # | State | Main action | Also shows |
|---|---|---|---|
| 1 | Not taking cases | Start taking cases | Prescriptions today |
| 2 | Taking cases, ready | Next order | End time + Extend, Stop, Prescriptions today |
| 3 | No cases right now | Try again (or Looking…, once verified) | End time, Stop |
| 4 | Window ending soon | Next order | "Ends in 15 min" + Extend |
| 5 | Window ended after a case | Extend | Done for now |
| 6 | Window ended while idle | Start again | "Your window ended at 6:00 PM" |
| 7 | Offline | — (Next order disabled) | Offline strip |
| 8 | Session expired | Verify OTP (sheet) | — |

**Sheets:** start / extend time · help · notifications inbox · profile · passkey set-up fallback · crash report
prompt.

## Out of scope (decided)
- **Callbacks go to the pool** (agreed 2026-10-10). No callback card on Home. Same-doctor callbacks parked.
- **No case → Home → case navigation** during a live case; help is in the case header.
- Case history, statistics, training, settings: not on Home.
- First-login declarations (terms, confidentiality, telemedicine guidelines): onboarding, not Home.

## Later
- **Uber-style case offers** with accept/decline and background alerts. Needs explicit opt-in, response-time
  rules and its own design phase.
- Same-doctor callbacks · in-app support chat · push alerts for announcements.
